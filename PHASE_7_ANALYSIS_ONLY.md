# Phase 7 — XAUUSD News Intelligence Dashboard

The project is now explicitly an ANALYSIS system.

It does not place trades and does not require MT5.

The final user-facing product should answer:

1. What is the market expecting?
2. What result would be a genuine surprise?
3. What does that surprise imply for rates/USD/real yields?
4. What is the estimated XAUUSD direction and probability?
5. How large could the move reasonably be?
6. What are the bullish, bearish and mixed scenarios?
7. What confirms the interpretation after release?
8. What would invalidate the interpretation?
9. Is the event likely to be a clean directional move or a whipsaw?
10. What are the key XAUUSD levels/conditions to monitor?

The output should be a decision-support report, not a trade command.

Primary event flow:

PRE-RELEASE
Economic consensus
+ FedWatch
+ Dot Plot history
+ DXY
+ Treasury yields
+ real yields
+ XAUUSD structure
+ volatility
        ↓
XAUUSD PRE-NEWS PROBABILITY

RELEASE
Actual
− Consensus
        ↓
SURPRISE

POST-RELEASE
DXY reaction
+ 2Y reaction
+ real-yield reaction
+ XAUUSD reaction
        ↓
CONFIRM / CONTRADICT

FINAL REPORT
Direction probability
+ expected magnitude
+ scenario analysis
+ invalidation
+ confirmation
+ whipsaw risk
